# Max Character Avatar Assets

This directory contains the visual assets for Max, the hydration companion.

## Files
- `max-avatar.svg`: Scalable vector artwork of Max (80s retro synthwave skater style with cassette headphones and companion water droplet).
- `max-avatar.png`: 128x128 rasterized PNG of the Max character.

## Customizing the Avatar
You can easily replace the character with your own image, photo, or custom artwork:

1. **Option 1: Replace PNG**
   Replace `max-avatar.png` with any PNG image (recommended size: `128x128` or `256x256`, square ratio).

2. **Option 2: Replace SVG**
   Replace `max-avatar.svg` with your own SVG illustration.

3. **Reload Extension**
   After replacing the file, go to `chrome://extensions` and click the reload icon on **Max's Water Reminder**.
